# WebASCIITube

영상·사진 파일을 넣으면 윤곽선만 뽑아 아스키 문자로 브라우저 창 전체에 실시간 렌더링합니다.
파일은 브라우저 안에서만 처리되고 서버로 올라가지 않습니다.

## 사용
- 창에 파일을 끌어다 놓거나 `[ 파일 선택 ]`
- 하단 `[ ^ 옵션 ]`: 파일 바꾸기, 재생/소리, 글자 크기, 윤곽 기준, 문자 방식, 원본 색, 노이즈 줄이기, 얇은 선, 프레임 텍스트 복사
- 키: `Space` 재생/정지 · `O` 옵션 · `C` 복사 · `Esc` 닫기

## 렌더 방식
| 단계 | 내용 |
|---|---|
| 격자 | 글자 크기와 창 크기로 셀 격자 계산, 미디어 비율을 유지해 창 안에 맞춤(contain) |
| 샘플링 | 셀당 2~3 × 4~5 픽셀(정사각형 근사)로 축소 |
| 윤곽 | 밝기 소벨 → 셀별 구조 텐서로 주 방향 → `\| / - \` |
| 기준 | 셀 윤곽 세기 상위 5%(히스토그램) 대비 비율, 영상은 이동평균 |
| 출력 | Canvas 2D, 단색은 줄 단위 `fillText`, 원본 색은 셀 단위 (최대 30fps) |

## 개발
```bash
npm install
npm run dev
npm run build   # dist/
```
